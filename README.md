# 7ims-optimize
7ims Tweaker — приложение для оптимизации Windows. В одном окне собраны твики производительности и приватности, очистка системы от мусора, менеджер процессов и автозагрузки, а также быстрая оптимизация одним нажатием. Перед применением опасных твиков приложение просит подтверждение, а изменения можно откатить. Все действия выполняются локально на вашем компьютере.
